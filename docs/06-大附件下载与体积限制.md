## 如果确实要放进仓库

1. **Git LFS**（本机已装 git-lfs 2.5.2）：`git lfs install && git lfs track "*.zip" "*.rar" "*.mp4"`，
   但 GitHub 免费额度只有 1 GB 存储 / 月流量，1.3 GB 的主程序仍放不下。
2. **GitHub Release 附件**：单个附件上限 2 GB，更适合分发安装包，且不会撑爆 git 历史。
3. **只放下载说明**：保留本文档 + 飞书 token，让别人自行从原文档获取（推荐）。
