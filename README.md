## 提示词库：两种形态

- **[`prompts/individual/`](prompts/individual/)** — 一条提示词一个文件。文件内**第一行就是提示词原文**，可直接全选复制；末尾附来源脚注（名称、分类、原文位置）。按用途分在 `01-写文与改文` … `09-前置与反推` 九个目录。
- **[`prompts/collections/`](prompts/collections/)** — 按原文章节合并的 9 篇合集，保留上下文，适合通读。
- **[`prompts/catalog.json`](prompts/catalog.json)** — 程序化调用用：包含每个文件的路径、分类、字数和前 80 字预览。

> 两者内容完全来自同一份原文，没有改写。找单条提示词用 `individual/`，看整章逻辑用 `collections/`。
